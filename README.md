# 🥐 Family Bakery Website

A responsive bakery website built with **HTML5 and CSS3** as a frontend practice project.

The project focuses on recreating a multi-section bakery website while practicing page structure, styling, layouts, hover effects, and responsive design.

## 🌐 Live Demo

https://mennat-alah.github.io/Bakery-website/

## 📸 Project Overview

The website includes several sections designed to present a bakery's products, location, and contact information.

### Sections

- **Navigation Bar** — Links to the main website sections.
- **Hero Section** — Welcome message with call-to-action buttons.
- **About Us** — Introduction to the bakery.
- **Our Location** — Location information and supporting imagery.
- **Our Baking** — A collection of bakery product cards.
- **Contact Information** — Contact details and an embedded Google Map.
- **Footer** — Opening hours, locations, and navigation links.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ What I Practiced

- Structuring a multi-section webpage with HTML.
- Using CSS selectors and reusable classes.
- Working with the `float` property for layouts.
- Styling navigation links, buttons, and hover states.
- Using background images, overlays, and text alignment.
- Implementing responsive layouts with media queries.
- Working with margins, padding, widths, and the box model.
- Embedding Google Maps using an iframe.

## 📱 Responsive Design

The project includes media queries to adjust the layout for different screen sizes.

Responsive behavior is an ongoing area of improvement, including layout adjustments, horizontal overflow, and mobile navigation.

## 🎯 Project Goal

My goal was to strengthen my HTML and CSS fundamentals by building a complete webpage and solving layout and styling challenges through hands-on practice.
